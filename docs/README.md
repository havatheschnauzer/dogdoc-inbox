# DogDoc Inbox: Documentation

Detailed project documentation lives here. The repository root holds the front-page files (README, ROADMAP, CONTRIBUTING); this folder is for the longer-form material behind them.

## Contents

- **[Architecture](architecture.md):** how the pieces fit, showing the tool layers and a document's journey from import to display.
- **[Architecture Decision Records (`adr/`)](adr/):** the reasoning behind significant technical and product-architecture decisions, one record per decision.

More documentation, such as development setup, the data model, and the document-extraction pipeline, will be added here as the project takes shape.

Documentation may reference shared images from the top-level [`assets/`](../assets/) folder.
