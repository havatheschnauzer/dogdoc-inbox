# 0007. Contributor Covenant code of conduct

- **Status:** Accepted
- **Date:** 2026-09-05

## Context

DogDoc Inbox actively invites contributors and aims to be a welcoming, community-driven project. Participants — especially newcomers and non–full-time contributors — benefit from clear, recognized expectations for behavior and a defined process for handling problems, rather than norms that live only in the maintainer's head.

## Decision

Adopt the **Contributor Covenant, version 2.1** as the project's code of conduct, with **havatheschnauzer@gmail.com** as the reporting and enforcement contact. See [CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md).

## Trade-offs

**What we gain**

- A widely recognized, off-the-shelf standard contributors already trust — it reads as "standard and fair" rather than idiosyncratic, and it's instantly familiar from countless other projects.
- Clear behavioral expectations plus a tiered enforcement ladder, so issues can be handled consistently instead of ad hoc.
- Reinforces the welcoming, community-driven tone the project is deliberately cultivating.

**What it costs**

- We take on the responsibility to actually enforce it — a code of conduct is only credible if acted upon.
- The reporting contact must be monitored, with complaints handled promptly, fairly, and with the reporter's privacy respected.
