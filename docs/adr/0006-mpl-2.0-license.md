# 0006. MPL-2.0 license

- **Status:** Accepted
- **Date:** 2026-09-04

## Context

The project is open source and wants contributions to stay open, while still allowing the software to be combined with separately licensed components and used pragmatically.

## Decision

DogDoc Inbox is licensed under the **Mozilla Public License 2.0 (MPL-2.0)**. See [LICENSE](../../LICENSE).

## Trade-offs

**What we gain**

- Contributions stay open: distributed modifications to MPL-covered files must remain available under the MPL.
- Unlike stronger copyleft, the project can still be combined with separately licensed software — pragmatic for real-world use and adoption.

**What it costs**

- We give up maximal permissiveness (MIT/Apache): redistributors cannot take MPL files closed-source, which a few commercial users avoid.
- We also forgo strong copyleft (GPL): it will not force an entire derived work to open up, if that were ever a goal.

Contributions are made under MPL-2.0 (see [CONTRIBUTING.md](../../CONTRIBUTING.md)).
