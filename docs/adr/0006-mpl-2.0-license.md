# 0006. MPL-2.0 license

- **Status:** Accepted
- **Date:** 2026-09-04

## Context

The project is open source and wants contributions to stay open, while still allowing the software to be combined with separately licensed components and used pragmatically.

## Decision

DogDoc Inbox is licensed under the **Mozilla Public License 2.0 (MPL-2.0)**. See [LICENSE](../../LICENSE).

## Consequences

- File-level copyleft: distributed modifications to MPL-covered source files must remain available under the MPL.
- The project can still be combined with separately licensed software, unlike stronger copyleft licenses.
- Contributions are made under MPL-2.0 (see [CONTRIBUTING.md](../../CONTRIBUTING.md)).
